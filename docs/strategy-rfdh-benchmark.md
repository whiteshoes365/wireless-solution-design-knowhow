# rfdh.com STUDY 벤치마킹 — 지식 베이스 고도화 전략

> 작성일: 2026-07-18 · 대상: 무선모듈 HW 설계 지식 베이스
> 성격: **전략 수립 문서(구현 전)**. 승인 후 단계별 실행.

---

## 결론 (먼저)

1. **베낄 것은 콘텐츠가 아니라 "교육 철학"이다.** rfdh.com의 진짜 강점은 정보량이 아니라, RF 엔지니어가 매일 쓰면서도 깊이 모르는 것들의 **"왜?"를 질문 형태로 파고들어 직관을 만들어 주는 방식**이다. (50Ω을 왜 쓰나 / dB를 왜 쓰나 / 공진이란 무엇인가 …)
2. **우리 사이트는 "How-to·프로세스"에 강하지만 "Why·직관"이 얇다.** 설계 흐름·PCB·안테나·검증·양산은 실무 체크리스트로 탄탄하나, 초심자가 개념을 *체득*하게 만드는 1차 원리 설명은 부분적이다.
3. **전략 = 실무 정체성은 지키고 직관 레이어만 이식.** rfdh를 이론 교과서로 복제하는 게 아니라, 질문-우선(Why-First) 설명을 **기존 실무 스파인 위에 얹는다.** 우선순위 3가지:
   - **① 직관 갭 6개 토픽 보강** (아래 §3)
   - **② "왜-먼저(Why-First)" 설명 컴포넌트 표준화** (§4 Pillar B)
   - **③ rfdh를 외부 참고문헌으로 출처 표기** — 차별화 + 저작권 안전 (§4 Pillar C, §7)

## 1. rfdh.com STUDY 구조 (관찰)

첨부 이미지 + 웹 확인 기준. STUDY 탭 하위 강의실:

| 강의실 | 성격 |
|---|---|
| **RF 기초강의실** | 핵심. 질문형 개념 강의 (아래 3분류) |
| 초청강의실 | 외부 전문가 강의 |
| RF database | 자료·데이터 모음 |
| RF & 통신 | 통신 관점 확장 |
| RF tools | 계산기·유틸 |

**RF 기초강의실**의 3분류 (rfdh의 대표 콘텐츠):

- **일반 기초**: RF 공부하기 / RF 기초공부 과목 / RF와 통신의 차이점 / Port의 의미 / RF 교육과정 / 대학원에서 RF 연구
- **원초적 기초** ★핵심: 50Ω을 쓰는 이유 / 마이크로스트립을 왜 쓸까 / Port의 정확한 의미 / 임피던스 매칭을 하는 이유 / S파라미터를 쓰는 이유 / dB를 왜 쓸까 / dB와 dBm의 차이
- **RF 회로의 기초**: RF의 범위 / RF관점에서 본 L과 C / 발진을 잡아라 / 대신호와 소신호의 차이 / 공진(Resonance)의 이해 / IF(중간주파수) 존재 이유

> 관찰: 제목이 전부 **"왜/무엇/차이"의 질문형**이다. 이것이 rfdh의 시그니처.

## 2. 포지셔닝 대조 — 겹치지 않게 차별화

| 축 | rfdh.com | 우리 사이트 |
|---|---|---|
| 도메인 | 범용 RF/마이크로파 이론·교육 | **가전·IoT 무선모듈 HW 실무** |
| 서술 방식 | 질문-우선, 직관·1차원리 | 프로세스·체크리스트·설계결정 |
| 독자 | RF 입문 학생·엔지니어 일반 | 모듈 HW 설계 실무자(입문~중급) |
| 강점 | "왜 이런가"를 깨닫게 함 | "무엇을 빠뜨리지 않을까"를 잡아줌 |
| 약점 | 특정 제품·양산 실무는 약함 | 개념 *체득* 유도가 약함 |

**시사점**: 두 사이트는 **상호보완**. 우리는 rfdh의 직관력을 흡수하되, "가전 무선모듈"이라는 실무 앵글을 절대 놓지 않아야 차별화가 유지된다. (이론 교과서화 = 자기잠식)

## 3. 갭 분석 (근거: 현재 content.js 실측 검색)

현재 콘텐츠에서 rfdh 핵심 개념의 등장 빈도로 커버리지를 판정:

| rfdh 토픽 | 현재 커버 | 판정 | 넣을 위치(제안) |
|---|---|---|---|
| **대신호 vs 소신호** | 0회 | 🔴 신규 필요 | 1장 or 4장(PA/LNA) — S파라미터=소신호, PA=대신호, P1dB/압축 |
| **RF관점의 L과 C (기생·자기공진 SRF)** | 1회 | 🔴 보강 시급 | 1장 신규 딥다이브 — "캐패시터가 고주파에선 인덕터가 된다" |
| **공진(Resonance)의 이해** | 산발 7회 | 🟡 통합 필요 | 1장 — 매칭·안테나·필터·XTAL의 공통 뿌리로 통합 설명 |
| **Port·기준면(reference plane)** | 1회 | 🟡 보강 | 1장 매칭/스미스 앞단 — "측정 기준면"이 왜 중요한가 |
| **S파라미터를 왜 쓰나** | 1회 | 🟡 보강 | 1장 — 고주파에선 open/short 불가 → 반사/전달로 정의 |
| **발진을 잡아라 (증폭기 안정도)** | 15회(대부분 발진기/XTAL) | 🟡 확인·보강 | 4장 프론트엔드 — LNA/PA 원치 않는 발진·안정계수 |
| 왜 전송선/마이크로스트립인가 | 12회(사용법 위주) | 🟢 소보강 | 1장/5장 — "선이 길어지면 전압이 위치마다 다르다" |
| 50Ω·dB·dBm·매칭 이유 | 충분 | ✅ 유지 | 이미 강함 — **재작성 금지**(중복) |

★ **최우선 4개**: 대신호/소신호, L과 C(기생·SRF), 공진 통합, Port·기준면.

## 4. 전략 3 Pillar (상세)

### Pillar A — 직관 갭 콘텐츠 보강 (원본 창작)

- §3의 🔴🟡 항목을 **기존 섹션에 자연스럽게 편입**(신규 탭 생성 지양 — 구조 비대화 방지).
- 각 토픽은 **우리 도메인 예시로 재작성**: 예) "대신호/소신호" → 가전 모듈 PA 출력 압축(P1dB)과 EVM 열화로 연결. rfdh 텍스트는 **참고만**, 문장·그림은 100% 자체 제작.
- 기존의 애니메이션 SVG 표준(kb-flow/kb-pulse 등)으로 개념 도식 동반.

### Pillar B — "왜-먼저(Why-First)" 설명 컴포넌트 표준화

rfdh의 힘을 **재사용 가능한 패턴**으로 만든다. 각 핵심 개념에 5단 구조 적용:

```
① 일상 비유 (1~2문장)          ← 이미 note kind:"info"(비유로 먼저) 있음
② 1차 원리 (왜 그런가, 공식)    ← note kind:"why" 활용
③ 흔한 오해 / 직관 함정         ← 신규 패턴 제안
④ 우리 도메인 실무 연결         ← note kind:"tip"(현장 노하우)
⑤ 더 깊이(외부 참고: rfdh 등)  ← 출처 링크
```

- 구현 부담 최소화: **새 블록 타입 없이 기존 note kind 조합**으로 규약화(문서화만).
- 선택적으로 `note kind:"myth"`(오해 바로잡기) 1종만 신설 검토.

### Pillar C — 포지셔닝·윤리 (차별화 + 저작권)

- rfdh 텍스트/이미지 **복제 금지**. 토픽 목록·아이디어(사실)는 저작권 대상 아님 → **자체 서술**로 재구성.
- 각 보강 개념 하단에 **"더 깊이 보기: rfdh.com RF 기초강의실"** 외부 참고 링크로 **출처 존중 + 신뢰도 확보**. (사이트의 기존 오픈라이선스 원칙과 일관)
- 실무 앵글 유지로 자기잠식 방지: "가전 무선모듈"이라는 정체성을 모든 보강에 각인.

## 5. 실행 로드맵 (승인 후 단계 실행)

| Phase | 내용 | 규모(추정) | 효과 |
|---|---|---|---|
| **P1 (즉효)** ✅ 완료(2026-07-18) | 최우선 4개 직관 딥다이브 신규: 대신호/소신호(`rf-signal-levels`), L과 C(`rf-lc`), 공진 통합(`rf-resonance`), Port·기준면·S파라미터(`rf-port-sparam`) + 용어집 5건(SRF·P1dB·OIP3·소/대신호·Reference Plane) | 섹션 4개(40블록), 도식 4개, 교차링크 22개 | 입문자 개념 체득 급상승 |
| **P2** ✅ 완료(2026-07-19) | Why-First 규약 문서화(`docs/why-first-authoring.md`) + 소급 적용: `rf-fundamentals`(dB 오해·rfdh 참고), `rf-impedance-matching`(변속기 비유·"50Ω 저항 매칭?" 오해·참고), `pcb-impedance`(λ/10 규칙·"50Ω=선 저항?" 오해). S파라미터 보강은 P1의 `rf-port-sparam`으로 충족. 기여 가이드(intro·README)에 규약 연결 | 규약 1건 + 3개 섹션 리터치 | 설명 일관성·품질 표준화 |
| **P3** ✅ 완료(2026-07-19) | 4장 `ckt-stability` 신규 — 발진을 잡아라(하울링 비유, Barkhausen 2조건, K-factor, 궤환 4경로 표, 디버깅 지문) + 궤환 루프 애니메이션 SVG + 교차링크(S12↔안정도, XTAL 부성저항과 대칭 구도) + 용어집 2건(K-factor·Barkhausen) | 딥다이브 1개(10블록) | 중급 심화·차별화 완성 |

> 각 Phase는 독립 배포 가능. P1만으로도 체감 효과 큼.

## 6. 안티패턴 (하지 말 것)

- ❌ rfdh 텍스트·그림 복사/번안 (저작권)
- ❌ 이론 교과서화 — 실무 프로세스 스파인 훼손 → rfdh와 차별성 상실
- ❌ 이미 강한 주제(50Ω/dB/dBm/매칭 이유) 재작성 → 중복·비대화
- ❌ 신규 탭 남발 → 현재 탭 구조(HW과정/WiFi/BT/Zigbee) 정체성 흐림. **기존 장에 편입** 원칙
